# Mathematical English

A practical reference for expressing mathematics, statistics, machine learning, physics, and engineering in English.

This repository collects common mathematical expressions, sentence patterns, and technical vocabulary used to describe mathematical ideas in English.

The goal is not simply to memorize vocabulary, but to learn how to **construct mathematical explanations in English**.

---

## Why This Repository?

Mathematical English uses a relatively small set of recurring expressions.

For example:

* Let \(x\) be a real number.
* Assume that \(x > 0\).
* Suppose that \(f(x)\) is continuous.
* For all \(x \in \mathbb{R}\), ...
* There exists a value \(x\) such that ...
* We define \(f(x)\) as ...
* Substitute \(x = 2\) into the equation.
* Differentiate \(f(x)\) with respect to \(x\).
* The sequence converges to \(0\).
* Minimize the loss function.

Once these patterns become familiar, mathematical explanations in English become much more structured and predictable.

## Foundations

The `foundations/` section contains the most reusable patterns for constructing mathematical sentences.

### Definitions

Expressions used to introduce variables, functions, and concepts.

Examples:

> Let \(x\) be an integer.

> Let \(y\) denote the output variable.

> We define the function as \(f(x) = x^2\).

### Assumptions

Expressions used to state assumptions.

Examples:

> Assume that \(x > 0\).

> Suppose that \(f(x)\) is continuous.

### Conditions

Expressions used to describe mathematical conditions.

Examples:

> For all \(x \in \mathbb{R}\), ...

> There exists a value \(x\) such that \(f(x) = 0\).

> If \(x > 0\), then \(x^2 > 0\).

### Relationships

Expressions used to describe mathematical relationships.

Examples:

> \(y\) is proportional to \(x\).

> \(f(x)\) approaches \(1\) as \(x\) increases.

> The sequence converges to \(0\).

## How to Use This Repository

A useful way to study each expression is:

```text
Expression
    ↓
Meaning
    ↓
Mathematical Example
    ↓
English Explanation
    ↓
Japanese Interpretation
```

For example:

### Expression

> Let \(x\) be a real number.

### Meaning

Introduce \(x\) as a real-valued variable.

### Mathematical Context

> Let \(x\) be a real number greater than zero.

### Japanese

> \(x\) を0より大きい実数とする。

---

## Guiding Principle

The central idea of this repository is:

> **Mathematical formulation → English expression → Example → Interpretation**

Mathematics is not only about manipulating equations.

It is also about explaining assumptions, defining variables, describing relationships, deriving results, and interpreting them clearly.

This repository aims to make those explanations easier to construct in English.
