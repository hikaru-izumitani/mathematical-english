# Assumptions

Common English expressions used to state assumptions and premises in mathematics, statistics, science, and engineering.

| English                                         | Japanese Meaning  | Example                                                       |
| ----------------------------------------------- | ----------------- | ------------------------------------------------------------- |
| **Assume that ...**                             | …と仮定する            | Assume that \(x > 0\).                                        |
| **Suppose that ...**                            | …と仮定する            | Suppose that \(f(x)\) is continuous.                          |
| **Assume \(x\) is ...**                         | \(x\) が…であると仮定する  | Assume \(x\) is a positive integer.                           |
| **Suppose \(x\) is ...**                        | \(x\) が…であると仮定する  | Suppose \(x\) is normally distributed.                        |
| **Given that ...**                              | …が与えられたとき／…を前提として | Given that \(x=2\), calculate \(f(x)\).                       |
| **Given ...**                                   | …が与えられて           | Given the data, we estimate the parameters.                   |
| **Under the assumption that ...**               | …という仮定のもとで        | Under the assumption that the errors are independent, ...     |
| **Assuming that ...**                           | …と仮定すると／…を仮定して    | Assuming that \(x>0\), we obtain the following result.        |
| **On the assumption that ...**                  | …という仮定に基づいて       | On the assumption that the model is correct, ...              |
| **Let us assume that ...**                      | …と仮定しよう           | Let us assume that the variables are independent.             |
| **For simplicity, assume that ...**             | 簡単化のため…と仮定する      | For simplicity, assume that the population variance is known. |
| **Without loss of generality, assume that ...** | 一般性を失うことなく…と仮定する  | Without loss of generality, assume that \(x>0\).              |

## Examples in Context

### Assume that ...

> Assume that \(x > 0\).

**Japanese:**
\(x\) は0より大きいと仮定する。

---

### Suppose that ...

> Suppose that \(X\) follows a normal distribution.

**Japanese:**
\(X\) が正規分布に従うと仮定する。

---

### Given that ...

> Given that \(x=2\), calculate \(f(x)\).

**Japanese:**
\(x=2\) が与えられたとき、\(f(x)\) を計算する。

---

### Assuming that ...

> Assuming that the observations are independent, we can apply this method.

**Japanese:**
観測値が独立であると仮定すると、この手法を適用できる。

---

### Under the assumption that ...

> Under the assumption that the errors are normally distributed, the estimator has the following distribution.

**Japanese:**
誤差が正規分布に従うという仮定のもとで、推定量は次の分布に従う。

---

### For simplicity, assume that ...

> For simplicity, assume that the population variance is known.

**Japanese:**
簡単化のため、母分散が既知であると仮定する。

---

### Without loss of generality, assume that ...

> Without loss of generality, assume that \(x \geq 0\).

**Japanese:**
一般性を失うことなく、\(x \geq 0\) と仮定する。

---

## Quick Reference

| Expression                                      | Main Use          |
| ----------------------------------------------- | ----------------- |
| **Assume that ...**                             | 基本的な仮定            |
| **Suppose that ...**                            | 条件を仮定して議論を始める     |
| **Given that ...**                              | 与えられた条件・前提を示す     |
| **Assuming that ...**                           | 「…と仮定すると」という条件を作る |
| **Under the assumption that ...**               | 仮定のもとで結果を述べる      |
| **For simplicity, assume that ...**             | 簡単化のための仮定         |
| **Without loss of generality, assume that ...** | 一般性を失わない仮定        |

## Common Pattern

A very common mathematical structure is:

> **Assume that [condition]. Then, [result].**

Example:

> Assume that \(x>0\). Then, \(x^2>0\).

**Japanese:**
\(x>0\) と仮定する。すると、\(x^2>0\) である。
