# Definitions

Common English expressions used to define variables, quantities, and mathematical concepts.

| English                   | Japanese Meaning        | Example                                         |
| ------------------------- | ----------------------- | ----------------------------------------------- |
| **Let \(x\) be ...**      | \(x\) を…とする             | Let \(x\) be a real number.                     |
| **Let \(x\) denote ...**  | \(x\) を…とする／\(x\) は…を表す | Let \(x\) denote the input variable.            |
| **Define ... as ...**     | …を…として定義する              | We define the function as \(f(x)=x^2\).         |
| **be defined as ...**     | …と定義される                 | The variance is defined as \(E[(X-\mu)^2]\).    |
| **represent ...**         | …を表す                    | The vector \(x\) represents the input features. |
| **represent ... by ...**  | …を…で表す                  | We represent the data by a vector \(x\).        |
| **refer to ... as ...**   | …を…と呼ぶ                  | We refer to \(x\) as the independent variable.  |
| **be denoted by ...**     | …で表される                  | The population mean is denoted by \(\mu\).      |
| **be represented by ...** | …で表される                  | The output is represented by \(y\).             |

## Examples in Context

### Let

> Let \(x\) be a positive integer.

**Japanese:** \(x\) を正の整数とする。

### Denote

> Let \(y\) denote the predicted value.

**Japanese:** \(y\) を予測値とする。

### Define

> We define the loss function as the mean squared error.

**Japanese:** 損失関数を平均二乗誤差として定義する。

### Represent

> The vector \(x\) represents the input features.

**Japanese:** ベクトル \(x\) は入力特徴量を表す。

### Refer to

> We refer to this quantity as the expected value.

**Japanese:** この量を期待値と呼ぶ。

## Quick Reference

| Expression                | Main Use       |
| ------------------------- | -------------- |
| **Let \(x\) be ...**      | 変数を導入する        |
| **Let \(x\) denote ...**  | 記号と量を対応させる     |
| **Define ... as ...**     | 定義する           |
| **represent ...**         | 何かを表す          |
| **refer to ... as ...**   | 何かを〜と呼ぶ        |
| **be denoted by ...**     | 記号で表される        |
| **be represented by ...** | 記号・ベクトルなどで表される |
