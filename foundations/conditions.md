# Conditions

Common English expressions used to describe conditions, constraints, existence, and logical relationships in mathematics, statistics, science, and engineering.

| English                           | Japanese Meaning | Example                                                                     |
| --------------------------------- | ---------------- | --------------------------------------------------------------------------- |
| **If ...**                        | もし…なら            | If \(x>0\), then \(x^2>0\).                                                 |
| **If and only if ...**            | …である場合、かつその場合に限る | \(x>0\) if and only if \(x^2>0\) and \(x\neq0\).                            |
| **Only if ...**                   | …の場合に限り          | The equation has a solution only if \(b\geq0\).                             |
| **Unless ...**                    | …でない限り           | The equation has no solution unless \(b\geq0\).                             |
| **For all \(x\)**                 | すべての \(x\) に対して  | For all \(x\in\mathbb{R}\), \(x^2\geq0\).                                   |
| **For any \(x\)**                 | 任意の \(x\) に対して   | For any \(x\), \(f(x)\geq0\).                                               |
| **There exists ...**              | …が存在する           | There exists a value \(x\) such that \(f(x)=0\).                            |
| **There exists at least one ...** | 少なくとも1つ…が存在する    | There exists at least one solution.                                         |
| **There exists a unique ...**     | 一意な…が存在する        | There exists a unique solution.                                             |
| **Such that ...**                 | …を満たすような         | Find \(x\) such that \(x^2=4\).                                             |
| **Subject to ...**                | …という制約のもとで       | Minimize \(f(x)\) subject to \(x\geq0\).                                    |
| **Provided that ...**             | …であることを条件として     | The method works provided that the assumptions hold.                        |
| **As long as ...**                | …である限り           | The algorithm converges as long as the learning rate is sufficiently small. |
| **In the case where ...**         | …の場合には           | In the case where \(x=0\), the result is undefined.                         |
| **Under the condition that ...**  | …という条件のもとで       | Under the condition that \(x>0\), the function is increasing.               |
| **Within the range of ...**       | …の範囲内で           | The value must remain within the range of \(0\) to \(1\).                   |
| **Greater than ...**              | …より大きい           | \(x\) is greater than \(0\).                                                |
| **Less than ...**                 | …より小さい           | \(x\) is less than \(10\).                                                  |
| **At least ...**                  | 少なくとも…           | The sample must contain at least 100 observations.                          |
| **At most ...**                   | 最大で…／多くとも…       | The error must be at most \(0.05\).                                         |

## Examples in Context

### If ... then ...

> If \(x>0\), then \(x^2>0\).

**Japanese:**
\(x>0\) ならば、\(x^2>0\) である。

---

### If and only if

> A matrix is invertible if and only if its determinant is nonzero.

**Japanese:**
行列が可逆であるのは、その行列式が0でない場合、かつその場合に限る。

---

### For all ...

> For all \(x\in\mathbb{R}\), \(x^2\geq0\).

**Japanese:**
すべての実数 \(x\) に対して、\(x^2\geq0\) である。

---

### There exists ...

> There exists a value \(x\) such that \(f(x)=0\).

**Japanese:**
\(f(x)=0\) を満たす \(x\) が存在する。

---

### Such that ...

> Find a value \(x\) such that \(x^2=9\).

**Japanese:**
\(x^2=9\) を満たす \(x\) を求めよ。

---

### Subject to ...

> Minimize the loss function subject to \(x\geq0\).

**Japanese:**
\(x\geq0\) という制約のもとで損失関数を最小化する。

**Machine Learning / Optimization:**
この表現は最適化問題で非常によく使われる。

---

### Provided that ...

> The estimator is unbiased provided that the assumptions are satisfied.

**Japanese:**
仮定が満たされることを条件として、その推定量は不偏である。

---

### At least / At most

> The sample must contain at least 100 observations.

**Japanese:**
標本には少なくとも100個の観測値が必要である。

> The prediction error must be at most 5%.

**Japanese:**
予測誤差は最大5%でなければならない。

---

## Mathematical Logic

Some expressions are especially important when describing logical relationships.

| English                                | Japanese Meaning | Example                                                 |
| -------------------------------------- | ---------------- | ------------------------------------------------------- |
| **necessary condition**                | 必要条件             | \(x>0\) is a necessary condition for ...                |
| **sufficient condition**               | 十分条件             | \(x>1\) is a sufficient condition for ...               |
| **necessary and sufficient condition** | 必要十分条件           | \(x>0\) is a necessary and sufficient condition for ... |
| **implies**                            | …を意味する／…を導く      | \(x>0\) implies \(x^2>0\).                              |
| **is equivalent to**                   | …と同値である          | These two conditions are equivalent.                    |
| **is consistent with**                 | …と整合する           | The result is consistent with the assumption.           |
